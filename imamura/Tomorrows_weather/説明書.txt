====================================================
 明日の天気アプリ（Tomorrows_weather） 説明書
====================================================

■ アプリの概要
--------------------------------------------------
このアプリは、ウェザーニュース（https://weathernews.jp/）から
栃木県宇都宮市の「明日の天気」の情報を取得し、ウィンドウ画面に
分かりやすく表示するデスクトップアプリです。

表示される情報:
  ・明日の日付
  ・天気（アイコン付き。晴れ/くもり/雨/雪/雷など）
  ・最高気温
  ・最低気温
  ・平均気温（推定）
      ※ウェザーニュースのページに平均気温の記載がないため、
        「（最高気温＋最低気温）÷2」で算出した参考値です。
  ・午前／午後の降水確率
  ・傘が必要かどうかの判定


■ フォルダの中身
--------------------------------------------------
  weather_app.py   ... アプリ本体（Pythonスクリプト）
  build_exe.bat    ... アプリをexe化（実行ファイル化）するための
                        ビルド用バッチファイル
  説明書.txt        ... このファイル


■ 使い方（初回のみ：exe化する場合）
--------------------------------------------------
 1. あらかじめパソコンに Python がインストールされている必要が
    あります（インストール時に「Add python.exe to PATH」に
    チェックを入れてインストールしてください）。

 2. 「build_exe.bat」をダブルクリックします。
    自動的に以下が行われます。
      ・必要なライブラリ（pyinstaller, requests, beautifulsoup4）
        のインストール
      ・weather_app.py を元にした exe ファイルの作成

 3. ビルドが完了すると、このフォルダの中に
    「dist」フォルダが作成され、その中に
    「TomorrowsWeather.exe」が生成されます。

 4. 以降は「TomorrowsWeather.exe」をダブルクリックするだけで
    アプリを起動できます（Pythonが入っていないパソコンでも
    このexeファイル単体で起動できます）。

 ※ exe化せず、Pythonが使える環境であれば
   「weather_app.py」を直接ダブルクリック、または
   コマンドプロンプトで次のように実行しても起動できます。

     python weather_app.py

   その場合は事前に次のコマンドでライブラリを入れてください。

     python -m pip install requests beautifulsoup4


■ 画面の見方
--------------------------------------------------
  上部    : 地域名（栃木県宇都宮市）
  中央上部: 明日の日付・天気アイコン・天気の説明
  中央    : 最高気温／最低気温／平均気温（推定）
  中央下部: 午前の降水確率／午後の降水確率
  下部の帯: 傘が必要かどうかの判定メッセージ
            （色でも分かりやすく表示されます）
  「更新」ボタン: 押すと最新の情報を取得し直します


■ 傘の要否の判定基準
--------------------------------------------------
  午前・午後どちらかの降水確率が
    50%以上        → 「傘が必要です」（赤）
    30%〜49%       → 「念のため折りたたみ傘があると安心です」（黄）
    30%未満        → 「傘は不要です」（緑）


■ 対象地域を変える場合
--------------------------------------------------
「weather_app.py」の上のほうにある、以下の部分を書き換えると
別の地域の天気に変更できます。

  LOCATION_NAME = "栃木県宇都宮市"
  SOURCE_URL = "https://weathernews.jp/onebox/tenki/tochigi/09201/"

SOURCE_URL は、ウェザーニュースのサイトで調べたい地域の
「今日明日の天気」ページのURL（例のような
「weathernews.jp/onebox/tenki/○○/○○○○○/」の形式）に
変更してください。変更後、build_exe.bat を再実行すると
exeファイルにも反映されます。


■ 注意事項・トラブルシューティング
--------------------------------------------------
・このアプリはウェザーニュースのページの内容を読み取って
  表示する仕組みのため、インターネット接続が必要です。

・ウェザーニュース側でページのデザインや構成が変更されると、
  天気情報がうまく取得できなくなる場合があります。
  その場合は画面に「取得に失敗しました」「取得できませんでした」
  と表示されますので、その旨をお知らせください。修正いたします。

・「python が見つかりません」等のエラーでビルドに失敗する場合は、
  Pythonが未インストール、またはPATHが通っていない可能性があります。
  Pythonを再インストールする際に「Add python.exe to PATH」に
  チェックを入れてください。

・本アプリは個人利用を目的としています。
