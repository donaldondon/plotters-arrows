# Cafe向け天気連動型おすすめメニュー提案と自動発信用アプリケーションSaaS

季節や気温（天気）に合わせて、今売りたいメニューの提案から発信までを自動化・効率化する
マルチテナント型のサブスクリプションSaaSです。

不特定多数の飲食店・カフェ事業者に月額課金で提供することを前提としており、
単一店舗向けのローカルツールではなく、クラウド上で複数テナントを同時に運用する
サービスとして設計されています。詳細な仕様は開発設計書
「Cafe向け天気連動型おすすめメニュー提案と自動発信用アプリケーションSaaS 開発設計書」を参照してください。

Hestiā（宇都宮市のカフェ）は本サービスの最初の有償顧客（パイロット導入店舗）です。

## セットアップ手順（フロントエンド）

```bash
cd frontend
npm install
cp ../.env.example .env.local   # 値を埋める
npm run dev
```

`http://localhost:3000` で開発サーバーが起動します。


## セットアップ手順（Supabase）

1. [Supabase](https://supabase.com) でプロジェクトを作成し、URL / anonキー / service_roleキーを
   `.env.local` に設定する。
2. Supabase CLIでマイグレーションを適用する。

```bash
supabase link --project-ref <your-project-ref>
supabase db push          # supabase/migrations/ の内容をDBに反映
supabase db seed          # supabase/seed.sql のダミーデータを投入（任意）
```


## 開発の進め方

各担当領域は開発設計書の章立てと1対1で対応しています。実装するファイルのコメントに
「設計書: フロントエンド設計(1)」のように参照先を記載しているので、詳細な仕様は
必ず開発設計書側を確認してください。本リポジトリのコードはその実装であり、
仕様そのものを定義するものではありません。
