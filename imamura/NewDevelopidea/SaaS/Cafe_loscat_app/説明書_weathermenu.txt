====================================================
 Hestiā 天気連動メニュー提案・自動発信ツール 説明書
====================================================

■ 概要
--------------------------------------------------
このアプリは、宇都宮市の天気予報（ウェザーニュース）を取得し、
その日の気象条件（寒い・暑い・猛暑・雨・普通）に合ったメニューを
在庫状況から選んで、
  1) 店内デジタル看板用のキャッチコピー
  2) SNS投稿の下書き文
  3) 簡単な看板画像（PNG）
を自動で作成するツールです。ロス削減のため、売り切りたいメニューを
優先的におすすめする仕組みになっています。

文章はまず簡単なルールで下書きを作り、OpenAIのAPIキーを入力すると
その下書きをHestiāのブランドトーン（暖炉・家族をイメージした、
あたたかく親しみやすい雰囲気）に沿って自然な文章に仕上げます。
APIキーを入力しない場合は、ルールベースの下書きがそのまま使えます。


■ フォルダの中身
--------------------------------------------------
  weathermenu_app.py         ... アプリ本体
  cafe_menu_data.py          ... メニュー一覧と対応天気タグのデータ
  stock_input.csv            ... 本日の在庫（毎日編集するファイル）
  build_exe_weathermenu.bat  ... ダブルクリックで WeatherMenuApp.exe を
                                  ビルドするスクリプト
  説明書_weathermenu.txt      ... このファイル

  ビルド後にできるもの:
  dist\WeatherMenuApp.exe    ... アプリ本体（exe化したもの）
  dist\stock_input.csv       ... 在庫ファイル（exeと同じ場所）
  signage_output\            ... 生成した看板画像(PNG)の保存先
                                  （アプリ実行時に自動で作成されます）


■ 使い方（毎日の流れ）
--------------------------------------------------
  1. stock_input.csv を開き、「本日の提供可能数」列に
     今日出せる数（在庫）を入力して保存する
     （優先度の列は空欄のままでもOK。売り切りたいメニューには
      「高」と入力すると優先的におすすめされます）
  2. WeatherMenuApp.exe（またはPythonから weathermenu_app.py）を起動する
  3. 画面上部で「今日」か「明日」を選び、「天気を取得」を押す
     → 天気・気温と、それに合った気象タグ（寒い日／雨の日など）が表示される
  4. 「おすすめメニュー候補」の一覧から、実際に案内したいメニューを選ぶ
     （在庫が多いものや売り切り優先度「高」のものが自動で選択されています。
      Ctrlキーを押しながらクリックすると選択を追加・解除できます）
  5. OpenAIのAPIキーをお持ちの場合は入力欄に入力する（無くてもOK）
  6. 「文章を生成」を押すと、看板用コピーとSNS投稿の下書きが表示される
  7. 内容を確認し、必要であれば手直しする
  8. 「看板画像(PNG)を生成して保存」を押すと、signage_output フォルダに
     画像が保存される（この画像をデジタルサイネージに表示してください）


■ exe化の方法
--------------------------------------------------
  1. build_exe_weathermenu.bat をダブルクリックする
     （必要なライブラリの自動インストール→ビルドが順に実行されます）
  2. 完了すると dist フォルダに WeatherMenuApp.exe が作成されます
  3. dist フォルダをまるごとお店のパソコンにコピーすれば、
     Pythonが入っていないパソコンでも実行できます


■ 気象タグの判定基準
--------------------------------------------------
  猛暑日  … 最高気温が35℃以上
  暑い日  … 最高気温が28℃以上（猛暑日と重複することがあります）
  寒い日  … 最高気温が10℃以下
  雨の日  … 天気に「雨」「雪」「雷」が含まれる、または
            降水確率（午前・午後のいずれか）が50%以上
  普通の日 … 上記のどれにも当てはまらない場合

  1つの天気に複数のタグが付くことがあります
  （例: 最高36℃・雨 → 「猛暑日」「暑い日」「雨の日」）。
  メニュー側もタグを複数持てるので、いずれか1つでも一致すれば
  候補として表示されます。


■ メニューと天気タグについて（重要）
--------------------------------------------------
cafe_menu_data.py の各メニューには、いただいたメニュー表と
「寒い雨の日→ナポリタン＋ホットココア」「猛暑日→アイスカフェオレ＋
プレーンシフォン」という例をもとに、Claudeの判断で天気タグを
割り当てています。実際の売れ行きや季節感と違う組み合わせがあれば、
cafe_menu_data.py 内の該当メニューの "tags": {...} の部分を
書き換えることで自由に調整できます
（タグの種類は "寒い日","猛暑日","暑い日","雨の日","普通の日" の5種類）。


■ 在庫の管理方法について（重要）
--------------------------------------------------
いただいた材料の在庫データ（合算月間使用量・現在在庫）は、
月間の合計使用量のみで1杯・1皿あたりの使用量が分からないため、
「在庫から作れる杯数」を自動計算することができませんでした。
また開業前のため、材料在庫は現在すべて0という状況です。

そのため本ツールでは、材料単位ではなく「メニュー単位」で
在庫数を直接入力する方式にしています（stock_input.csv）。
開業後、実際の仕込み数量が分かるようになったら、
stock_input.csv の「本日の提供可能数」に、その日その日で
用意した数量を入力してご利用ください。

もし将来的に「材料在庫から自動計算する」方式に変更したい場合は、
メニューごとの1杯・1皿あたりの材料使用量（レシピ原価表のような
データ）をいただければ、その方式に作り直すことも可能です。


■ SNS投稿・看板コピーの文体について
--------------------------------------------------
教えていただいた「家族でゆっくりできるイメージ（暖炉・家族を
意味する店名のため）」を反映するよう、weathermenu_app.py の
BRAND_CONCEPT / SNS_STYLE_HINT に設定しています。
文体の印象を変えたい場合は、この2つの値を書き換えてください。


■ 看板画像について
--------------------------------------------------
画像は暖色系（テラコッタ・オレンジ系）の配色で、天気アイコン
（太陽・雲・雨・雪・雷を簡単な図形で表現したもの。絵文字は
文字化けの可能性があるため使用していません）、おすすめメニューの
一覧、看板コピーを1枚のPNG画像にまとめたものです。
イメージカラーを変更したい場合は、weathermenu_app.py の
COLOR_BG_TOP・COLOR_BG_BOTTOM・COLOR_HEADER・COLOR_ACCENT・
COLOR_RIBBON の値（RGB）を編集してください。


■ トラブルシューティング
--------------------------------------------------
・「天気の取得に失敗しました」と表示される
    → インターネット接続を確認してください。ウェザーニュースの
      ページ構造が変わった場合は取得できなくなることがあります。

・「おすすめメニューが見つかりません」と表示される
    → stock_input.csv の「本日の提供可能数」が0のままになって
      いないか確認してください。

・生成AIでの仕上げに失敗する
    → OpenAIのAPIキーが正しいか、利用上限に達していないかを
      ご確認ください。失敗した場合はルールベースの文章が
      自動的に表示されます。

・看板画像の日本語が四角や記号に文字化けする
    → お使いのパソコンにMeiryo・游ゴシック・MSゴシックの
      いずれかのフォントが入っていない可能性があります。
      通常のWindowsパソコンであれば標準搭載されています。
